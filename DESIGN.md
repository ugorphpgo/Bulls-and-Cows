# Bulls and Cows — DESIGN

Игровая логика лежит в `src/logic/` (чистые функции, без DOM и классов), экран — в `src/ui/main.ts`.

## 1. Структуры данных и алгоритмы

### Состояние игры

Состояние текущей партии — объект `game` в `src/ui/main.ts`:

| Поле             | Тип              | Зачем                                                                                                                               |
| ---------------- | ---------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `secret`         | `string`         | Загаданное число. Строка, а не число: секрет может начинаться с нуля (`0123` как число стало бы `123`)                              |
| `length`, `base` | `number`, `Base` | Настройки партии. `Base = 2 \| 8 \| 10 \| 16` — union вместо `number`, поэтому TypeScript не даст передать неподдерживаемую систему |
| `history`        | `Attempt[]`      | История попыток `{ guess, bulls, cows }` в порядке ходов                                                                            |
| `startTime`      | `number`         | Время начала партии (`Date.now()`), из него считается время игры                                                                    |

**История пополняется иммутабельно:** `game.history = [...game.history, attempt]`. Старый массив не меняется, создаётся новый с добавленной попыткой. Повторная догадка проверяется через `history.some(...)` и в историю не попадает.

**Алфавит цифр** — массив `baseChars` (`'0123456789abcdef'`) в `src/logic/baseChars.ts`. Цифры системы — это первые `base` символов: `baseChars.slice(0, base)`. Алфавит описан в одном месте, и генератор, и валидатор берут его оттуда.

**Рекорды** — массив `{ attempts, time, length, base }` в `localStorage` под ключом `bulls-and-cows-records`. Одна общая таблица, у каждой записи подписаны система и длина. Хранятся 10 лучших: сортировка по числу попыток, при равенстве — по времени.

### `generateSecret(length, base, random)`

«Мешок с фишками»: в начале в мешке все цифры системы. `length` раз выбирается случайный индекс `Math.floor(random() * мешок.length)`, цифра добавляется в секрет и удаляется из мешка через `filter`. Поэтому цифры не повторяются. Источник случайности `random` приходит параметром: в игре это `Math.random`, в тестах — функция с заранее известной последовательностью чисел, и результат можно проверить точно.

### `createDigitValidator(base)`

Каррированная фабрика: внешняя функция один раз вычисляет алфавит системы, внутренняя `(char) => boolean` проверяет один символ (ровно один символ, после `toLowerCase` есть в алфавите). Используется в двух местах: в `isValidGuess` как предикат для `every` и в `filterInput` на экране для фильтрации ввода в реальном времени.

### `isValidGuess(guess, length, base)`

Три проверки через `&&`: длина совпадает, каждая цифра проходит валидатор (`Array.from(guess).every(isDigit)`), повторов нет (`new Set(guess.toLowerCase()).size === guess.length`). Нижний регистр перед `Set` нужен, чтобы `a` и `A` считались одной цифрой.

### `evaluateGuess(secret, guess)`

Без ручных счётчиков, двумя `filter`:

- **быки** — символы догадки, которые совпадают с символом секрета на той же позиции;
- **совпадения** — символы догадки, которые вообще есть в секрете;
- **коровы** = совпадения − быки.

Формула работает, потому что цифры в секрете и догадке не повторяются: каждая цифра догадки считается не больше одного раза.

### `countPossibleSecrets(length, base)`

Число возможных секретов — размещения без повторений: `base × (base − 1) × … ` (`length` множителей). Рекурсия: `count(length, base) = base × count(length − 1, base − 1)`, точка остановки `count(0, base) = 1`. Мемоизация: `Map`, ключ — строка `` `${length}-${base}` ``. Перед вычислением функция ищет ответ в кэше, после вычисления кладёт его туда.

## 2. Сложность

Обозначения: `n` — длина секрета (`length`, от 2 до 6), `b` — основание системы (`base`, до 16).

| Функция                | Время                             | Почему                                                                                                     |
| ---------------------- | --------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `generateSecret`       | O(n · b)                          | `n` итераций, на каждой `filter` проходит мешок длиной до `b`                                              |
| `isValidGuess`         | O(n · b)                          | `every` проверяет `n` символов, каждый — `includes` по алфавиту длиной `b`; `Set` — O(n)                   |
| `evaluateGuess`        | O(n²)                             | быки — один проход O(n); совпадения — для каждого из `n` символов `includes` по секрету длиной `n`         |
| `countPossibleSecrets` | O(n) первый вызов, O(1) повторный | рекурсия делает `n` вызовов до точки остановки; повторный вызов с теми же аргументами берёт ответ из `Map` |

Память: `countPossibleSecrets` хранит до `n` записей в кэше на каждую пару аргументов и использует стек глубиной `n`. При `n ≤ 6` все оценки — константы на практике, но порядок роста именно такой.

## 3. Принципы чистого кода

| Принцип                              | Где                                                                                                                                                                        |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Одна функция — одна задача (SRP)** | `isValidGuess` только проверяет догадку, `evaluateGuess` только считает быков и коров и не валидирует вход; экран (`checkGuess` в `src/ui/main.ts`) вызывает их по очереди |
| **Чистые функции**                   | Всё в `src/logic/`: одинаковые аргументы → одинаковый результат, без DOM и глобального состояния. Случайность вынесена в параметр `random` у `generateSecret`              |
| **DRY**                              | Алфавит цифр описан один раз в `src/logic/baseChars.ts`; валидатор цифр написан один раз и переиспользуется в `isValidGuess` и `filterInput`                               |
| **Говорящие имена**                  | `isValidGuess`, `createDigitValidator`, `countPossibleSecrets`, `lowerGuess`; булевы функции начинаются с `is`                                                             |
| **Типы вместо проверок**             | `Base = 2 \| 8 \| 10 \| 16` — неподдерживаемую систему отсекает TypeScript ещё до запуска                                                                                  |
| **Иммутабельность**                  | история попыток и рекорды создаются заново через spread (`[...history, attempt]`), без `push`                                                                              |
